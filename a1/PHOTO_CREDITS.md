## Reuse conditions and teaching clarity

- The Commons file pages above contain authors, license details and usage conditions. **Credit is required** for photographs under CC BY and CC BY-SA. Files marked CC0 or public domain have different conditions; provenance is credited here regardless.
- Photographs are **not the original textbook artwork**. They are generic illustrative examples and **do not identify fictional characters** in practice dialogues.
- Some photo sets contain several objects, while others represent only one object. Study questions should ask only about what is actually visible, and the **written grammar tables remain authoritative** for spelling, conjugations, numbers and dates.
- No photograph is cropped or altered by this course; GitHub displays the externally hosted image.
- External links can change. If an image breaks, use its source file page to find the current media and replace the link.
- The original course-created SVGs were removed from the lesson pages because learners found them difficult to interpret.
